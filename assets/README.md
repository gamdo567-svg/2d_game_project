# assets

게임 에셋(픽셀풍 2D 그래픽, 사운드, 폰트)을 보관하는 폴더입니다.

| 폴더 | 용도 |
|---|---|
| `images/` | 스프라이트, 타일셋, UI 이미지 (PNG 권장) |
| `sounds/` | 효과음(WAV), 배경음(OGG/MP3) |
| `fonts/` | 게임에서 사용하는 폰트 파일 |

## 규칙

- 외부 에셋을 추가할 때는 아래 **출처 및 라이선스** 표에 반드시 기록합니다.
- 라이선스가 불분명한 에셋은 커밋하지 않습니다.
- 에셋 추가 커밋은 `assets:` 형식을 사용합니다. 예: `assets: 플레이어 대기 스프라이트 추가`
- 파일 이름은 영문 소문자와 밑줄을 사용합니다. 예: `player_idle.png`

### 주인공 스프라이트

- 형식: 상태·방향마다 PNG 한 장. 32×48px 프레임을 가로로 이어 붙인 투명 배경(RGBA) 시트. idle은 5프레임(160×48), walk는 4프레임(128×48).
- `side`는 오른쪽을 보는 그림이며, 왼쪽은 게임에서 좌우 반전해 그립니다.
- 캐릭터 본체만 포함합니다. 검은 포함하지 않습니다.
#### Walk (2026-11-03 교체)

- 원본: 1182×1330px, 3행(정면·후면·오른쪽 측면) × 4열. 배경은 거의 순수 초록(실측 약 `(4, 248, 4)`)이고, 캐릭터 한 명은 약 160~180 × 315~331px.
  원본 도트 한 칸이 약 4~5px이지만 정확한 격자가 아니고 경계가 부드럽게 번져 있습니다.
- 균등 분할하지 않고 초록이 아닌 픽셀의 연결 요소 12개로 실제 캐릭터 위치를 찾았습니다.
- 초록 제거: 초록 정도로 알파를 추정하고, 반투명 경계는 배경색을 역계산해 빼고 남은 초록 기운을 없앴습니다(디스필).
- 축소: 12프레임 모두 같은 축척(약 1/7.3)으로 면적 평균 축소 후, 알파 0.5 기준으로 완전 불투명/투명만 남겼습니다. 결과에 반투명·초록 픽셀 0개.
- 정렬: 가장 낮은 발 픽셀을 맨 아래 줄에, 후드 중심을 기존 Idle과 같은 x에 맞췄습니다(DECISIONS D-016).
- 알려진 문제: 원본 도트(약 72px 높이)를 48px로 줄였기 때문에 벨트 버클·장갑 등 작은 장식이 뭉개집니다. 다리 교차는 잘 보입니다.
  측면 Walk는 다리를 벌린 자세라 측면 Idle(임시 에셋)보다 키가 약 3px 작습니다.

#### Idle (임시 에셋)

- 추출 방법: 참고 시트의 Idle/Walk 행에서 프레임별로 배경색 `(20, 20, 28)`을 테두리부터 지우고(색 거리 12 이하), 25픽셀 미만 잡티를 지운 뒤,
  모든 프레임에 같은 축척(약 0.5배)을 적용해 축소하고 반투명 가장자리를 없앴습니다. 발 기준선은 상태·방향별 5프레임 중 가장 낮은 바닥에 맞췄습니다.
- 알려진 문제: 원본이 픽셀 격자에 맞춘 도트 그림이 아니어서 축소 후 윤곽이 거칩니다. 배경과 색이 가까운 어두운 옷 부분이 일부 투명해졌을 수 있습니다.
  Walk 측면은 뒷발 일부가 몸통과 떨어져 보이는 프레임이 있습니다.
  ~~참고 시트의 Walk 프레임 자체가 서로 거의 같아서 게임에서 걷는 동작이 잘 보이지 않습니다.~~ (2026-11-03 Walk는 새 참고 시트로 교체)
  **Idle은 완성된 게임용 에셋이 아닙니다.** 새 Walk와 색감·선 굵기가 달라 정지↔이동 전환 때 그림체 차이가 보이므로, Walk와 같은 방식(초록 배경 참고 시트)으로 다시 만드는 것을 권합니다.

> 현재 화면의 글자는 pico2d 패키지에 포함된 기본 폰트(`ConsolaMalgun.ttf`)를 사용하며, 이 폴더에 복사하지 않습니다.
